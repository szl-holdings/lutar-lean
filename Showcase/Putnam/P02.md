# P02 — Classic / Putnam-style number theory  ·  **REAL**

## Problem

For every natural number `n`,

> `6 ∣ n³ − n`.

We formalize the equivalent, subtraction-free congruence
`n ^ 3 % 6 = n % 6`  (i.e. `n³ ≡ n (mod 6)`), which on `ℕ` is logically
equivalent to `6 ∣ n³ − n`.

## Honest attribution

This is the classic `n³ ≡ n (mod 6)` fact — a standard **Putnam-style**
number-theory warm-up — **not** a specific Putnam-year problem. It is included
to demonstrate a genuine, axiom-clean `decide`-backed REAL proof next to the
purely algebraic P01.

## Proof

The map `x ↦ x³ mod 6` depends only on `x mod 6`, so the claim reduces to a
finite check over the six residue classes.

1. Rewrite `n ^ 3` as `n * n * n` (core `pow` unfolding).
2. Establish the finite fact by `decide`:
   `∀ r : Fin 6, ((r·r % 6)·r) % 6 = r`.
3. Push the outer product through `Nat.mul_mod` twice so the left side is written
   purely in terms of `n % 6`, then instantiate the finite fact at `r := n % 6`.

```lean
theorem cube_mod_six (n : Nat) : n ^ 3 % 6 = n % 6 := by
  have e : n ^ 3 = n * n * n := by
    simp [Nat.pow_succ, Nat.pow_zero, Nat.one_mul]
  have key : ∀ r : Fin 6, ((r.val * r.val % 6) * r.val) % 6 = r.val := by decide
  rw [e, Nat.mul_mod, Nat.mul_mod n n 6]
  have h := key ⟨n % 6, Nat.mod_lt _ (by decide)⟩
  simpa using h
```

## Why it's a faithful formalization

`n ^ 3 % 6 = n % 6` says precisely that `6` divides `n³ − n`: two naturals are
congruent mod 6 iff their difference is a multiple of 6. The proof makes no
appeal to Mathlib's divisibility machinery — only core `Nat` arithmetic and a
decidable residue check — keeping the axiom footprint to `propext`.
