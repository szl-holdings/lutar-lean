# P03 — Putnam 2019 A1  ·  **REAL**

## Problem

Determine all nonnegative integers `n` that can be written as

> `A³ + B³ + C³ − 3ABC`

for some nonnegative integers `A, B, C`.

**Answer:** exactly the `n` with `n % 9 ∉ {3, 6}`.

## Formalized statement

```lean
def cyclicForm (A B C : Int) : Int := A ^ 3 + B ^ 3 + C ^ 3 - 3 * A * B * C

theorem putnam2019A1_iff (n : Int) (hn : 0 ≤ n) :
    (∃ A B C : Int, 0 ≤ A ∧ 0 ≤ B ∧ 0 ≤ C ∧ cyclicForm A B C = n)
      ↔ (n % 9 ≠ 3 ∧ n % 9 ≠ 6) := ...
```

We work over `ℤ` (with the explicit `0 ≤ ·` side-conditions) so that the cubic
form is total — subtraction on `ℕ` truncates and would distort the statement.

## Proof outline

- **Necessity** (`⇒`): with `s = A + B + C` and `P = AB + BC + CA`, the identity
  `A³ + B³ + C³ − 3ABC = s³ − 3·s·P` holds over `ℤ` (lemma `hexp`, the only step
  needing commutativity — closed by `polyC`). Treating `P` as a single opaque
  integer (`cubeForm_emod9`) and splitting on `s % 3` shows `s³ − 3·s·P` is never
  `≡ 3` or `6 (mod 9)`. This replaces the brute 9³-case residue table with three
  `polyA`+`omega` lines.
- **Sufficiency** (`⇐`): explicit witnesses by residue class of `n % 3`:
  - `n = 3m+1`:  `cyclicForm (m+1) m m   = 3m+1`;
  - `n = 3m+2`:  `cyclicForm (m+1) (m+1) m = 3m+2`;
  - `n = 9k`  :  `cyclicForm (k+1) k (k−1) = 9k` (and `(0,0,0)` for `n = 0`);
    when `n % 3 = 0`, excluding residues `3, 6` forces `n % 9 = 0`.
