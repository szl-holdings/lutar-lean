# P03 — Putnam 2019 A1  ·  **DEMO**

## Problem

Determine all nonnegative integers `n` that can be written as

> `A³ + B³ + C³ − 3ABC`

for some nonnegative integers `A, B, C`.

**Answer (the statement we formalize):** exactly the `n` with `n % 9 ∉ {3, 6}`.

## Honesty label: DEMO

- The *statement* is formalized and typechecks against core Lean, but the proof
  is `sorry`.

## Formalized statement

```lean
def cyclicForm (A B C : Int) : Int := A ^ 3 + B ^ 3 + C ^ 3 - 3 * A * B * C

theorem putnam2019A1_iff (n : Int) (hn : 0 ≤ n) :
    (∃ A B C : Int, 0 ≤ A ∧ 0 ≤ B ∧ 0 ≤ C ∧ cyclicForm A B C = n)
      ↔ (n % 9 ≠ 3 ∧ n % 9 ≠ 6) := by
  sorry
```

We work over `ℤ` (with the explicit `0 ≤ ·` side-conditions) so that the cubic
form is total — subtraction on `ℕ` truncates and would distort the statement.

## What a REAL proof would require (why this is DEMO)

- **Necessity** (`⇒`): use the factorization
  `A³ + B³ + C³ − 3ABC = (A + B + C)(A² + B² + C² − AB − BC − CA)`
  together with a residue analysis modulo 9 to rule out `n ≡ 3, 6 (mod 9)`.
- **Sufficiency** (`⇐`): give explicit constructions covering every other
  residue class (e.g. `(A,B,C) = (m,0,0)`, `(m+1,m,m)`, etc.), which realize all
  `n` with `n % 9 ∉ {3,6}`.

Both directions are genuine Mathlib-scale developments. Rather than fake a REAL
label, we ship a faithful statement scaffold and mark it DEMO.
