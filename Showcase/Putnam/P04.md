# P04 — Putnam 2020 A2  ·  **DEMO**

## Problem

Let `k` be a nonnegative integer. Evaluate

> `∑_{j=0}^{k} 2^{k−j} · C(k+j, j)`.

**Answer:** `4^k`.

## Honesty label: DEMO

- The *statement* is formalized and typechecks against core Lean, but the proof
  is `sorry`.
- `#print axioms putSum_eq_four_pow` would therefore report `sorryAx`.
- This file is intentionally **not** labeled REAL.

Lean source: [`../PutnamLean/P04.lean`](../PutnamLean/P04.lean).

## Formalized statement

Because `Nat.choose` is not in the core prelude, we define `binom` ourselves via
Pascal's rule, then state the sum and the closed form:

```lean
def binom : Nat → Nat → Nat
  | _,     0     => 1
  | 0,     _+1   => 0
  | n+1, k+1 => binom n k + binom n (k + 1)

def putSum (k : Nat) : Nat :=
  (List.range (k + 1)).foldl (fun acc j => acc + 2 ^ (k - j) * binom (k + j) j) 0

theorem putSum_eq_four_pow (k : Nat) : putSum k = 4 ^ k := by
  sorry
```

## Statement sanity check (evidence, not proof)

The file includes an `#eval` that prints `(putSum k, 4 ^ k, putSum k == 4 ^ k)`
for `k = 0 … 7`; all eight agree:

| k | putSum k | 4^k |
|---|----------|-----|
| 0 | 1 | 1 |
| 1 | 4 | 4 |
| 2 | 16 | 16 |
| 3 | 64 | 64 |
| 4 | 256 | 256 |
| 5 | 1024 | 1024 |
| 6 | 4096 | 4096 |
| 7 | 16384 | 16384 |

Computational agreement is strong evidence that the statement is transcribed
correctly, but it is **not** a kernel proof — hence the DEMO label.

## What a REAL proof would require (why this is DEMO)

A clean induction on `k` using the Pascal recurrence for `binom`, or a generating
-function / snake-oil identity argument, formalized against Mathlib's
`Nat.choose` lemmas. That development is deferred; the showcase ships the
faithful, eval-validated statement scaffold instead of a fabricated REAL label.
