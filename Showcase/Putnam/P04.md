# P04 — Putnam 2020 A2  ·  **REAL**

## Problem

Let `k` be a nonnegative integer. Evaluate

> `∑_{j=0}^{k} 2^{k−j} · C(k+j, j)`.

**Answer:** `4^k`.

## Formalized statement

Because `Nat.choose` is not in the core prelude, we define `binom` ourselves via
Pascal's rule, then state the sum and the closed form:

```lean
def binom : Nat → Nat → Nat
  | _,     0     => 1
  | 0,     _+1   => 0
  | n+1, k+1 => binom n k + binom n (k + 1)

def putSum (k : Nat) : Nat :=
  (List.range (k + 1)).foldl (fun acc j => acc + 2 ^ (k - j) * binom (k + j) j) 0

theorem putSum_eq_four_pow (k : Nat) : putSum k = 4 ^ k := ...
```

## Proof outline

The proof is a self-contained, Mathlib-free development:

- **Auxiliary accumulator.** Define `S n k = ∑_{j=0}^{k} 2^{k−j} · binom (n+j) j`
  by its recurrence `S n 0 = 1`, `S n (k+1) = 2·S n k + binom (n+k+1) (k+1)`
  (`R1`, definitional). The target sum satisfies `putSum k = S k k`.
- **Pascal toolkit.** Definitional `binom_pascal`; over-diagonal vanishing
  `binom_lt`; diagonal `binom_self = 1`; the subtraction-free complementary
  symmetry `binom (a+b) a = binom (a+b) b` (`binom_symm`, a nested induction);
  and its corollary `binom (2k+2) (k+1) = 2·binom (2k+1) k` (`binom_D`).
- **Additive recurrence** `R3 : S (n+1) k + binom (n+k+1) k = 2·S n k`
  (induction on `k`; each step is one Pascal expansion plus linear arithmetic
  over the `binom`/`S` atoms, closed by `omega`).
- **Diagonal** `S k k = 4^k` (induction on `k`): `R1`, `R3 k k`, and `binom_D`
  combine so the two `binom` terms cancel, leaving `S (k+1) (k+1) = 4·S k k`.
- **Bridge** `putSum k = S k k`: the partial `foldl` up to index `m` equals
  `2^(k−m) · S k m` for `m ≤ k` (induction on `m`, peeling the last summand with
  `List.range_succ`/`List.foldl_append`); specialize at `m = k`, where the
  prefactor `2^(k−k) = 1`.
