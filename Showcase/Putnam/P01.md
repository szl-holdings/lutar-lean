# P01 — Putnam 2001 A1  ·  **REAL**

## Problem

A binary operation `*` on a set `S` satisfies

> `(a * b) * a = b`   for all `a, b ∈ S`.

Prove that `a * (b * a) = b` for all `a, b ∈ S`.

## Honesty label: REAL

- Complete, kernel-checked proof; **zero `sorry`**.

  `propext`).
- Mathlib-free; compiles against `leanprover/lean4:v4.18.0` core.

## Proof

Write `H a b : (a * b) * a = b` for the hypothesis. The goal is `a * (b * a) = b`.

1. Instantiate `H` at the pair `(b * a, b)`:
   `H (b*a) b : ((b*a) * b) * (b*a) = b`.
2. Instantiate `H` at the pair `(b, a)` to collapse the inner factor:
   `H b a : (b*a) * b = a`.
3. Rewriting `(b*a)*b ↦ a` inside step 1 turns it into `a * (b*a) = b`, which is
   exactly the goal.

The corresponding Lean tactic block is four lines:

```lean
theorem putnam2001A1 {S : Type _} (op : S → S → S)
    (H : ∀ a b, op (op a b) a = b) (a b : S) :
    op a (op b a) = b := by
  have key := H (op b a) b           -- ((b*a)*b)*(b*a) = b
  have hc : op (op b a) b = a := H b a  -- (b*a)*b = a
  rw [hc] at key                     -- a*(b*a) = b
  exact key
```

## Why it's a faithful formalization

The Lean statement quantifies over an arbitrary type `S` and an arbitrary
binary operation `op : S → S → S` with no extra structure, and the hypothesis
`H` is exactly the problem's universally quantified identity. The conclusion is
the problem's exact claim. Nothing about associativity, identity, or
commutativity is assumed.
